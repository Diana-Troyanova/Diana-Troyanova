## Проекты

### [MyNissan](https://github.com/Diana-Troyanova/mynissan)

Веб-приложение для Nissan Leaf и Nissan Ariya: интерактивные 3D-модели, показатели батареи, планирование поездок и журнал обслуживания. Для знакомства с интерфейсом доступен демонстрационный режим.

**Технологии:** HTML, CSS, JavaScript, Three.js, WebGL, localStorage.

[Открыть приложение](https://diana-troyanova.github.io/mynissan/) · [Посмотреть код](https://github.com/Diana-Troyanova/mynissan)

### [Сайт строительной лаборатории](https://github.com/Diana-Troyanova/stroylab-expert)

Многостраничный сайт строительной лаборатории с каталогом услуг, инженерным справочником и калькуляторами: уплотнение грунта, масса арматуры и объём бетона. Проект находится в разработке.

**Технологии:** HTML, CSS, JavaScript, SVG; Python для локального запуска и генерации региональных страниц.

[Посмотреть код и инструкцию запуска](https://github.com/Diana-Troyanova/stroylab-expert)
